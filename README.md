# 🍔 FOODIE CRUNCHES

**Foodie Crunches** is a responsive restaurant website designed to provide users with a simple and interactive online food-ordering experience.

The website presents the restaurant's information, menu categories, special offers, and an interactive order section where customers can select items, view their order total, enter their information, and place an order.

## ✨ Features

* 🏠 Attractive restaurant homepage
* 🍕 Categorized food menu
* 🍔 Pizza, burgers, drinks, and sweets
* 🛒 Add items to order
* 🔢 Automatic quantity handling
* 💰 Automatic order total calculation
* 🗑️ Remove individual items
* 🧹 Clear complete order
* 👤 Customer information form
* 📦 Order confirmation message
* 🎁 Special offers and deals section
* 📍 Restaurant information and location
* 📱 Responsive layout using Bootstrap
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Interactive ordering functionality
* **Bootstrap** — Responsive design and UI components
* **Bootstrap Icons** — Interface icons

## 🍽️ Menu Categories

The website includes:

* 🍕 Pizza
* 🍔 Burgers
* 🥤 Drinks
* 🍰 Sweets

Each menu item includes an **Add to Order** button that allows users to build their order interactively.

## 🛒 Ordering System

The ordering system allows users to:

1. Select food items from the menu.
2. Add items to their order.
3. Increase the quantity of an existing item.
4. Remove selected items.
5. Clear the complete order.
6. Enter customer name, phone number, and delivery address.
7. View the calculated order total.
8. Place the order and receive a confirmation message.
